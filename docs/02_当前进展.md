## 运行核验

在临时副本中使用 FastAPI TestClient 检查了 23 个点：18 项基础行为符合预期，5 项是缺口复现。不能将其表述为“23 项功能验收通过”。原工程未生成核验数据库或上传图片。

基础行为包括：三个页面与样式响应、空历史、无此报告、非法场景/MIME 拒绝、两场景演示上传、照片读取、模拟视觉结果落库、模拟模型失败入库、普通与代码块 JSON 解析、非法 JSON 拒绝。

五项复现缺口：非图片内容能用图片 MIME 上传；下游专业字段是占位；图片质量与部分不确定项丢失；无隐患结果增加隐患计数；没有健康接口。

另从代码确认：报告直接拼接模型文本至 `innerHTML`；未限制上传体积；`.env` 中数据路径配置未被读取；SQLite 事务上下文未显式关闭连接；客户端没有 JSON 解析重试；前端缺完善的失败兜底与防重复提交。

环境：Python 3.11.5、FastAPI 0.116.1、httpx 0.28.1、python-multipart 0.0.20、python-dotenv 0.21.0。环境中没有 `openai` 包，测试采用演示分支和模型替身。**未调用真实模型、未验收公网/移动端、未验证锁定依赖全新安装，也未进行浏览器视觉或安全利用测试。**

证据保留在团队本地工作区的 `项目文档/核验附件/results.json` 和 `prototype_audit_20260916.py`，不随本仓库上传。脚本的 `GAP` 检查刻意断言盘点时缺口存在；未来修复后应更新为正确行为的回归测试，不能拿历史缺口断言作为长期通过标准。
