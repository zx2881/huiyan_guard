# 规章来源与核验范围

本目录记录知识库所用文件的来源，不存放赛事资料、账号信息或未经授权的校内文件。`dormitory/regulations.json` 当前采用国家法律和教育部部门规章作为宿舍场景的公共基线，所有条款于 2026-09-17 对照官方网页核验。

## 已核验来源

1. 《高等学校消防安全管理规定》，教育部、公安部令第 28 号，自 2010 年 1 月 1 日起施行。来源：[中华人民共和国教育部政府门户网站](https://www.moe.gov.cn/srcsite/A03/s3013/201004/t20100427_91963.html)。本项目选取学生宿舍用火用电、消防设施、疏散通道、大功率电器、逃生障碍、危险品、明火、防火巡查和隐患整改相关条款。
2. 《中华人民共和国消防法》（2021 年修正）。来源：[国家市场监督管理总局政府信息公开页面](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_e9e34f0731c249a891ea9c925e17f237.html)。本项目选取第二十七条电器线路要求和第二十八条消防设施、通道及逃生障碍要求。
3. 《教育系统重大事故隐患判定指南》，教发厅函〔2024〕20 号。教育部原始页面未检索到可稳定访问的正文链接，当前通过[武汉市江夏区教育局政府信息公开页面](https://www.jiangxia.gov.cn/xxgk_22343/xxgkml_22349/zdlyxxgk_22437/jyly/202501/t20250103_2512293.shtml)核验其公开附件。本项目只选取“电动自行车（含电池）入楼、私拉乱接电线或飞线充电”的直接判定项；后续取得教育部原始链接后应替换来源 URL，并重新核验正文。

## 使用边界

- 条款原文用于提供可追溯依据，风险等级和整改期限不能从关键词命中自动推导。
- 同一现象可能命中多条条款，业务层应保留条款 ID、原文、来源链接和检索时间快照。
- 当前没有用户所在学校的正式学生公寓管理规定，因此知识库不包含某校对“大功率”的具体瓦数、禁用电器清单、检查频次或处分规则。团队取得本校现行正式文件后，应记录发文单位、文号、适用范围和核验日期，再按稳定 ID 补充；不得引用其他学校的内部制度冒充本校规则。
- 实验室场景目前只有检查清单，没有已核验法规数据，检索必须返回空结果，不能回填宿舍条款。
